## 阻塞与风险

- 当前无产品决策阻塞。
- npm 11 在多工作区存在同名不同主版本依赖时会错误提升旧版本；根工具链显式固定 AJV、LRU、semver 等构建依赖，便携生产安装已使用 `--workspaces=false` 隔离。
- `better-sqlite3` 的安装辅助包 `prebuild-install` 已弃用，但当前生产依赖审计为 0；后续升级原生模块时应重新验证便携安装。
- 自动化覆盖 Windows 11 与 Windows Server 2022/2025；若正式对外声明 Windows 10 客户端支持，仍建议在目标 Windows 10 实机补做一次启动器冒烟。
- 本地服务器已验证进程与管道，正式赛事服务器的账号权限、网络和策略仍应在赛前按发布配置彩排。

## 已确定决策

- 仅保留 `work` 工作模式和 `test` 测试模式。
- 工作模式必须由本服务托管真实 MockClient；不提供正式观察直播。
- 测试模式统一承载假 MockClient、静态/增长日志、虚拟时钟、播放和故障注入，禁止联网及真实命令。
- `2025-grandprix-sr1-13` 仅为参考资料，不进入默认 CI 或发布门禁；有价值的边界必须提炼为独立最小夹具。
- 有效完赛后再次出现同关 DNF 时，保留首次完赛，后续事件仅作异常留档。
- 达到最低计分名次只安排下一轮；上一轮接收窗口在下一轮实际进入 Ready 时原子关闭，若先到时限则以时限为准。
- 测试自动化使用独立虚拟时钟和内存回显执行器；工作自动化只通过串行命令队列推进，Go 未确认不得创建尝试。
- 恢复时 `sent` 命令统一转为 `uncertain`，敏感现场保持自动化暂停；无不确定命令和观察缺口时仍需裁判确认才能继续。
- 归档按模式分目录且版本只增不覆盖；清单固定记录数据模式、应用/解析器/MockClient 版本与逐文件 SHA-256。
- 生产服务只监听 `127.0.0.1:32113` 且端口冲突直接失败；开发实例仅凭本地随机关闭令牌替换，未知进程绝不自动终止。
- 便携包启动器使用包内 Node、自动打开带 URL fragment 令牌的浏览器，并随包提供关键文件清单和第三方许可证清单。
