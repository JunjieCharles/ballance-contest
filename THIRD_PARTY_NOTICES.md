The Windows portable package contains these redistributable components:

- Node.js 24 runtime. Its full upstream license and bundled third-party notices are copied to `licenses/Node.js-LICENSE.txt`.
- BallanceMMO server tools and libraries from `Swung0x48/BallanceMMO`, licensed under BSD-3-Clause. The license is copied to `server-windows/LICENSE` and `licenses/BallanceMMO-LICENSE.txt`.
- Production npm packages. The exact package name, installed version, declared license and resolved source are generated as `THIRD_PARTY_PACKAGES.json`; package-level license files remain in `node_modules`.

This inventory describes third-party components only. It is not legal advice and does not replace the license terms shipped with each component.
