## 命令行参数

#### 示例


#### 参数详解

- `-s ADDRESS`, **`--server=ADDRESS`**  
  指定服务器地址及端口，默认连接本地服务器：`127.0.0.1:26676`。  
  示例：`--server=192.168.1.2:26676`。
- `-n NAME`, **`--name=NAME`**  
  设置伪客户端在服务器中的昵称，便于识别。若名字前缀 `*`（请注意终端环境下可能需要转义）则会被视为旁观者模式。  
  默认名称为 `MockClient`。  
  示例：`--name=TestClient`。
- `-u UUID`, **`--uuid=UUID`**  
  指定 UUID，用于唯一标识客户端。默认 UUID 在第一次运行时随机生成，但可自定义并覆盖。  
  示例：`--uuid=123e4567-e89b-12d3-a456-426614174000`。
- `-l PATH`, **`--log=PATH`**  
  日志文件路径，若指定，则日志同时输出到文件和控制台。  
  示例：`--log=./client.log`。
- `-d LEVEL`, **`--detail=LEVEL`**  
  输出详细等级：`0` 为最低，`2` 为最高。  
  示例：`--detail=2`。
- `-r`, **`--recorder-mode`**  
  启用录制模式，所有收到的数据包保存为二进制文件，可以使用 `BallanceMMORecordParser` 读取并重放。  
  此外，录制模式下若未指定伪客户端的名称，则名称会被自动设置为 `*FlightRecorder`。
- **`--individual-packets`**  
  配合录制模式使用，单独保存每个数据包，可能产生大量小文件，慎用。
- **`--no-sound-files`**  
  不保存服务器推送的音效文件，节省磁盘空间。
- **`--auto-flush`**  
  每次日志输出后立即写入文件，防止日志丢失。
- `-p`, **`--print`**  
  显示玩家状态变化的详细信息，主要用于调试。
- `-h`, **`--help`**  
  显示所有支持参数的说明及用法。
- **`--version`**  
  显示程序版本、构建时间等信息并退出。

## 内部命令

伪客户端启动后，支持通过交互式控制台输入命令，模拟玩家操作或进行调试。以下为下文命令的描述格式和注意事项：

- 不同参数之间以空格分隔；未使用任何格式的参数表示玩家必须原样输入参数名称。
- `<参数>` 表示必须根据实际状态输入的参数。
- `[参数]` 表示可以省略（将会使用默认值）的玩家参数。
- `参数1|参数2` 表示玩家需要选择参数 1 或参数 2 中的一个填入。
- `{玩家}` 表示玩家名称或前缀了 # 的玩家内部临时 ID（可以用 `list` 获取）。
  * 例：若一玩家名为 Player，ID 为 1145141919，则可以输入 `Player` 或者 `#1145141919`。
- `{关卡}` 表示关卡名称或哈希值（可以用 `listmap` 获取），其有两种输入方式：
  * 原版关卡直接输入 `level 关卡号`，如 `level 12`。
  * 输入哈希值**及关卡号**（关卡号在此没有任何意义，但客户端仍需要接收），如 `1234567890abcdef1234567890abcdef 12`。哈希值可以通过 `listmap` 获取。
- 命令参数的完整名称以及玩家名或玩家 ID 可以输入首字母后在输入框内按下 Tab 键自动补全，方便快速输入。
- 固定的命令和玩家名不区分字母大小写，但玩家根据实际状态自行填入的其他参数区分。此外，Tab 键自动补全时由于补全库自身设定问题，也区分大小写。
- 控制台会对错误用法给出提示或警告。

### 核心管理

- `stop`  
  停止伪客户端。
- `reconnect [服务器地址]`  
  （断线后）重新连接到到服务器。地址留空则使用伪客户端启动时所配置的服务器地址。  
  值得注意的是，伪客户端断线后只可继续输入一次命令，此后会自动退出；若不期望伪客户端自动退出，则断线后只能执行 `reconnect` 命令以补救。
- `flushlog`  
  刷新日志文件。正常情况下不需要手动执行；服务器日志一般是先被写入内存缓冲区，定时或在特定事件后才写入磁盘，但有时（尤其是如果接了读取分析日志的外部插件时）需要手动刷新。

### 信息查询

- `list` 或 `l`  
  列出所有在线客户端（玩家和旁观者）。
- `getinfo`  
  显示客户端的一些连接信息，如延迟、连接质量等。
- `getinfo-detailed`  
  显示更加详细的连接状态信息。按下 `Q` 键退出。
- `getmap`  
  显示每位玩家当前地图和小节。
- `getpos`  
  显示每位玩家当前位置和球的类型。
- `listmap`  
  列出当前伪客户端内缓存的所有地图名称及其哈希值。

### 通讯命令

- `say <内容>` 或 `s <内容>`  
  向所有玩家发送聊天消息。
- `whisper {玩家} <内容>`  
  向指定玩家发送私聊消息。
- `announce <内容>`  
  向所有玩家发送重要通知（公告）。使用 `\n` 可以换行，用 `\\n` 可以在内容中包含 `\n` 字符。
- `notice <内容>`  
  向所有玩家发送提示通知，格式同上。
- `bulletin [内容]`  
  设置服务器公告（持久性通知），格式同上。内容留空等同于清除公告。客户端会在连接时自动获取当前公告内容；一般而言，客户端支持最多显示 3 行公告。公告会在服务器空载时（所有玩家均退出后）被自动清除。
- `getbulletin`  
  获取当前服务器公告内容（因为直接用 `bulletin` 命令会清除公告，所以需要用 `getbulletin` 获取当前公告内容）。

### 管理操作

- `kick {玩家} [原因]`  
  踢出玩家。可以通过连接 ID 或名称踢出，并附带原因。
- `crash {玩家} [原因]`  
  使玩家客户端崩溃，通常用于测试或强制断开。

### 竞速相关操作

- `cheat [on|off]`  
  全局禁用或启用作弊模式（Cheat Mode）。默认为全局关闭。
- `countdown {关卡} [模式] [类型]` 或 `cd {关卡} [模式] [类型]`  
  对置顶关卡和模式进行倒计时等发令。控制台会提示可用参数和类型（模式默认为 `sr`；类型 `4` 和 `5` 分别为预备和提醒预备，`0` 为起跑；不输入类型时服务器会自动倒数 3 秒后起跑）。直接输入 `countdown` 并回车后可以查看伪客户端内置的
帮助说明。  
  示例:
  * `cd level 2`——倒计时 3 秒后起跑第 2 关。
  * `countdown level 12 hs 0`——发令 HS 模式起跑第 12 关。
  * `countdown e90b2f535c8bf881e9cb83129fba241d 2 3`——倒计时 3 秒后起跑哈希值为 `e90b2...` 的第 2 关。
- `forcenextrestart`  
  若稍后发送比赛起跑命令，则所有玩家无视所在地图同时重开，并重置服务器内所有地图先前已有的排行名次（适用于多地图连续比赛但仅发号一次的场景）。被强制重开时地图名后会有 `*` 标记。
- `dnf {关卡} <小节>`  
  发送未完成（Did not finish；DNF）当前关卡的提示信息。
- `scores [local] <hs|sr> [{关卡}]`  
  查询指定关卡的排名得分信息（默认是最后一次接到发令的关卡，但可以重新指定）。正常情况下客户端会向服务器查询状态，但添加 `local` 可以查询本地缓存。
- `restartlevel {玩家}`  
  请求玩家当前关卡重开。
- `win {关卡} <hs|sr> <额外得分> <额外生命> <用时>`  
  通关当前关卡。用时单位为秒。

### 自身状态类

- `balltype [球种]`  
  设置伪客户端当前球种。`0` `1` `2` 分别为纸球、石球、木球。不写则默认为 `0`。
- `cheat-self [on|off]`  
  启用或禁用伪客户端的作弊模式（伪客户端不存在控球操作，因此本功能纯用于调试）。留空则是切换（反转）当前模式。
- `move [x] [y] [z] [旋转角度]`  
  将伪客户端的影子球移动到对应的坐标，不填则使用 ±10 之间的随机值。旋转角度为四元数。
- `translate [x] [y] [z] [旋转角度]`  
  将伪客户端的影子球平移对应的坐标，不填则使用 ±10 之间的随机值。旋转角度为四元数。
- `teleport {玩家}`  
  传送到指定玩家的位置。
- `setmap {关卡} [自定义名称]`  
  设置伪客户端当前所在的关卡，并尝试设置自定义名称（仅在服务器对对应地图没有缓存名称信息时可以成功）。
- `setsector [小节]`  
  设置当前所在小节。默认为 `0`，实际范围可以是任意 32 位整数。

### 帮助

- `help`  
  打印所有可用命令的帮助信息。

## 其他说明

- 使用录制、打印等调试功能时，请注意磁盘空间消耗。
